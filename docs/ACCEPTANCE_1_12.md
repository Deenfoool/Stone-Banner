# Stone & Banner — 1.12: приёмка P0–P5

**Версия исходников:** alpha.49. **Среда:** Minecraft Java 1.20.1 / Forge 47.4.23 / Java 17.
Эта инструкция — **чек-лист для запуска**, не отчёт о пройденной проверке.
Не отмечать успешными сценарии, которые не были реально выполнены.
Главная ветка `main`, GitHub Actions **не используются**.

## 0. Подготовка: сохранить старые настройки и мир

- Установить 64-битный JDK 17; `java -version` и `javac -version` должны показать 17.
- Сделать резервные копии `config/stonebanner-client.toml`, `options.txt`, save-миров;
  проверить версии клиента и сервера, mod JAR и `mods.toml`.
- Иметь отдельный чистый мир и копию существующего сохранения, не тестировать
  разрушение блоков/строительство на единственном оригинальном мире.
- Отключить сторонние моды для baseline; затем повторить проверку с дополнительными модами,
  которые изменяют управление или UI. Отсутствие конфликтов не следует предполагать заранее.

## 1. Автоматизированная проверка (P0, P1, P2, P3, P4, P5)

Linux / macOS, из корня репозитория:

```bash
bash scripts/verify-phase-1.12.sh
```

Windows PowerShell (JDK 17 выбран как `JAVA_HOME`):

```powershell
.\gradlew.bat --no-daemon --stacktrace clean test build verifyGameTests
```

Ожидается **код выхода 0**, зелёные JUnit тесты и успешная строка
`All N required tests passed` в `run-gametest/logs/latest.log`.
Задача `verifyGameTests` проверяет эту строку и проваливает Gradle при её отсутствии.
Особенно важны тесты:
`InputContractMatrixTest`, `ActionResolverTest`, `ScreenInputRulesTest`,
`HeroMovementRulesTest`, `HeroOrdersGestureTest`, `ToolBackGestureTest`,
`SettingPresetsTest`, `LocalizationParityTest`,
`TacticalActionPacketTest`, `TacticalOrdersPacketTest`,
`CitizenOrderQueueTest` и `HeroNavigationGameTests`.

Примечание: unit-тест **не** заменяет настоящий Forge-клиент с мышью, клавиатурой,
визуальными маркерами и настоящим игровым циклом.

## 2. P0 — приоритеты ввода и отсутствие двойных команд

1. Запустить `./gradlew runClient`, открыть мир. Наводить мышь на слот хотбара,
   миникарту, HUD NPC, уведомления, кнопку таба; нажать ЛКМ/ПКМ.
   **Ожидание:** UI выполняет только своё действие; герой не бьёт, не идёт,
   не использует блок, NPC не получает приказ.
2. В Minecraft `Настройки → Управление → Назначение клавиш` назначить Attack/Use
   сначала на мышь, затем на другую клавишу, проверить модификаторы и неактивные бинды.
   **Ожидание:** любая переназначенная кнопка на HUD также поглощается UI.
3. Войти в `Приказы → Земля`, начать объём тремя ЛКМ; один ПКМ откатывает шаг,
   быстрый двойной ПКМ очищает локальное выделение; на нулевом шаге ПКМ выходит
   из инструмента. Никакой ПКМ на обозначенном UI не создаёт мировой приказ.
4. Пока включена камера слежения за NPC, нажать разные кнопки HUD.
   **Ожидание:** HUD срабатывает с первого клика, фокус сам не сбрасывается.
5. Перейти в чат, инвентарь, меню настроек/паузы, затем обратно.
   **Ожидание:** невидимые обозначения не остаются активными, удержания и
   клики не воспроизводятся повторно, уже опубликованные работы на сервере остаются.

## 3. P1 — WASD/Mouse, плавание и навигация

- **WASD:** W/A/S/D относительно камеры; Shift приседание и погружение,
  Space прыжок и всплытие, Sprint ускорение. При ручном движении герой не должен
  продолжать автоматический маршрут против направления игрока.
- **Mouse:** ЛКМ по земле → цель; двойной ЛКМ или Sprint → бег; удержание →
  обновление цели с ограничением частоты запросов, без A* каждый тик.
  Alt+ЛКМ добавляет точку в очередь; новая прямая команда заменяет прежний путь.
- **Движение:** проверить лестницу, низкий потолок, спуск с обрыва, стоячую и
  движущуюся воду, нехватку воздуха, огонь/лаву, непрогруженные края мира,
  движущихся NPC на пути. **Ожидание:** отказ с причиной, никаких опасных
  «коротких путей», коллизии не проходят сквозь стены.
- Повторить с настройкой `safePath` вкл./выкл. Выкл. допускает менее строгий
  обход других существ, но **не** обходит базовые проверки границ, воды, огня,
  геометрии и загрузки чанков.

## 4. P2 — предметы и бой

- В обоих профилях: обычный ЛКМ/ПКМ по сундуку/двери/кнопке/верстаку,
  доступная и недоступная цель, `Alt+ПКМ` (меню альтернатив), пустая рука,
  кирка/топор, блок строительства, лук удержать/отпустить, melee по врагу
  и защищённому союзнику. Ущерб и изменение блоков должны подтверждаться сервером.
- `autoApproach = true`: далёкая цель вызывает ограниченный безопасный подход,
  достигает обычной дистанции взаимодействия; не атакует сквозь преграды.
  `autoApproach = false`: далёкая цель не запускает путь сама.
- При замене предмета, открытии GUI, смерти, потере фокуса и смене измерения
  удержание использования/лука и разрушения прекращается, не дублируя удар.

## 5. P3 — Hero ↔ Orders, группы и камера

1. Короткий Tab переводит в Orders, следующий — в Hero.
   Длинный Tab из Hero временно открывает Orders; отпускание возвращает Hero
   (если включён `holdTab`). При отключении этой опции Tab остаётся переключателем.
2. Выделить нескольких NPC (Shift+ЛКМ и рамка), переключить Hero и обратно.
   **Ожидание:** выделенная группа остаётся; в Hero тактическая карточка
   скрыта, в Orders появляется вновь.
3. `Ctrl+1…9` сохраняет группу, `Alt+1…9` возвращает её, двойное `Alt+номер`
   фокусирует камеру; настоящие слоты героя `1…9` остаются доступными.
4. Очередь перемещений/работ NPC после временного или обычного Tab
   продолжает обрабатываться сервером; она удаляется **только** явным Stop,
   новым прямым приказом или реальной серверной причиной прерывания.
5. Home — к герою; повторный Home — камера по умолчанию; краевая прокрутка
   и zoom проверяются отдельно в Hero и Orders. Избегать неверного фокуса
   на NPC после выгрузки чанка или его удаления.

## 6. P4 — HUD, GUI Scale, локализация, старый конфиг

- В игре, меню паузы и на стартовом экране открыть настройки Stone & Banner:
  Управление / Камера / HUD; покрутить числовые пресеты и переключатели,
  закрыть/открыть — значения сохранились. Контроль кнопки переназначения ведёт
  в ванильное Key Binds; `E/F/Esc/1…9` не должны перехватываться по ошибке.
- Проверить GUI Scale **2, 3, 4**, разрешение **1280×720**, **1920×1080** и
  небольшое окно. Ни подсказка, ни меню, ни маршрут не препятствуют клику.
- Переключить `ru_ru`, `en_us`, `de_de`, `zh_cn`: ключи настроек/подсказок
  переведены, остальные de/zh строки fallback на английский. Не должно быть
  пустых подписей или необработанных `%s`.
- Вернуть старый `stonebanner-client.toml` с `controlMode=TACTICAL` и
  нестандартным значением чувствительности; ожидание — Mouse и отсутствие
  произвольного сброса числа до выбора нового пресета. Проверить пользовательский
  `options.txt` после перезапуска. Исходники не переименовывают существующие
  Forge-контрольные поля.
- Включать/выключать отдельно маркеры, маршруты, подсказки, анимацию отклика;
  описание уже выполненных серверных задач не меняется.

## 7. P5 — выделенный сервер и старое сохранение

1. Собрать мод, запустить Forge 1.20.1 **dedicated server** через
   `./gradlew runServer` в отдельной dev-среде. Войти клиентом с **тем же**
   mod JAR и сетевым протоколом.
2. Проверить все команды NPC, торговлю, чаты, сквозные коллизии, блокировку
   атаки союзников, права управления, сохранение строительных/рабочих очередей
   после выхода и возврата. Скорость мира/удары/блоки остаются серверными.
3. Повторить ключевые действия с копией старого мира и конфигов:
   прерванная добыча, старые назначения, временные работы, переключение
   мира/измерения и повторная авторизация.
4. Просмотреть `logs/latest.log`, `run-gametest/logs/latest.log`,
   исключения на клиенте и сервере; дополнительно проверить TPS при частом
   смене целей и удержании курсора. **Нет числа FPS/TPS «по предположению».**
