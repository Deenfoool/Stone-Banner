# Stone & Banner — Roadmap

> Total-conversion мод для Minecraft: мир, блоки, сущности и визуальный язык остаются узнаваемым Minecraft, но управление, камера, экономика, развитие поселения и стратегические системы полностью переосмысливаются.

## Основные принципы проекта

- **Minecraft должен визуально оставаться Minecraft.** Не заменяем игру на отдельную voxel-стратегию: сохраняем блоки, биомы, рельеф, деревья, воду, деревни, мобов и пропорции Minecraft.
- **Камера и управление — не ванильные.** Основной режим — перспективная камера сверху/сзади в духе Baldur's Gate 3 с возможностью плавно менять дистанцию и переходить от управления персонажем к группе и поселению.
- **Бой идёт в реальном времени.** Без бросков кубиков и без пошаговой системы.
- **Игрок — не просто один персонаж.** Он управляет героем/командиром, группой, населением и развитием территории.
- **Строительство остаётся физическим Minecraft-строительством.** Здания состоят из настоящих блоков и существуют в настоящем мире.
- **Мир должен иметь стратегическую ценность.** Каждый чанк получает собственный ресурсный профиль, поэтому выбор территории, разведка, торговля и расширение становятся важными решениями.

# Phase 3 — Territory & Chunk Resource System

> Одна из центральных систем Stone & Banner. Каждый Minecraft-чанк `16×16` имеет собственный **профиль территории** и стратегическую ценность.

## 3.1 Профиль каждого чанка
Каждый чанк получает как минимум следующие характеристики:

- [ ] **Плодородие** — эффективность земледелия, пастбищ и будущих аграрных систем.
- [ ] **Лесные ресурсы** — доступность древесины и скорость восстановления леса.
- [ ] **Каменные ресурсы** — камень, песок, глина и другие нерудные материалы.
- [ ] **Рудный потенциал** — железо, уголь, медь, золото и другие залежи.
- [ ] **Водные ресурсы** — вода, рыба, орошение, доступ к реке/озеру.
- [ ] **Пригодность территории** — насколько удобно здесь строить, жить и развивать инфраструктуру.

## 3.2 Факторы расчёта
Характеристики чанка **не должны быть случайным набором цифр**. Они рассчитываются из мира Minecraft.

### Биом
- [ ] Plains → высокий базовый аграрный потенциал.
- [ ] Forest / Taiga → высокий лесной потенциал.
- [ ] Mountains / Stony биомы → камень и повышенный рудный потенциал.
- [ ] Desert → песок, низкое плодородие и дефицит воды.
- [ ] Swamp → вода, особые растения, сложность строительства.
- [ ] Другие биомы получают собственные профили и модификаторы.

### Высота
- [ ] Большая высота снижает часть аграрного потенциала.
- [ ] Скалистые высокие районы повышают каменный/рудный потенциал.
- [ ] Долины и низины могут получать аграрные бонусы.

### Рельеф
- [ ] Измерять перепад высот внутри чанка.
- [ ] Ровная земля получает высокий строительный потенциал.
- [ ] Сложный рельеф повышает стоимость/время строительства.
- [ ] Холмы и склоны могут давать оборонительные преимущества.

### Вода
- [ ] Наличие реки/озера внутри чанка.
- [ ] Расстояние до ближайшей постоянной воды.
- [ ] Бонусы к сельскому хозяйству и рыболовству.
- [ ] В будущем — речная логистика и торговля.

### Климат и влажность
- [ ] Температура.
- [ ] Влажность.
- [ ] Осадки / климатический профиль биома.
- [ ] Влияние на урожай, лес и доступные культуры.

### Подземная геология
- [ ] Независимый детерминированный geological noise по seed мира.
- [ ] Геологические зоны должны переходить через границы чанков.
- [ ] Богатые месторождения формируют крупные пятна/жилы, а не равномерно раздаются каждому чанку.
- [ ] Система должна быть совместима с фактической Minecraft-генерацией руд либо корректно накладываться на неё.

## 3.3 Особенности территории
Чанк может получить одну или несколько редких особенностей:

- [ ] Плодородная почва.
- [ ] Пойменные почвы.
- [ ] Густой лес.
- [ ] Глинистые почвы.
- [ ] Каменный пласт.
- [ ] Богатые залежи железа.
- [ ] Угольный пласт.
- [ ] Родник.
- [ ] Рыбные воды.
- [ ] Ягодники.
- [ ] Лекарственные растения.
- [ ] Заброшенная шахта.
- [ ] Древние руины.
- [ ] Естественная гавань / удобная переправа.
- [ ] Другие world-feature traits.

Особенности должны давать конкретные механические бонусы/штрафы, а не быть только декоративным текстом.

## 3.4 Возобновляемые и невозобновляемые ресурсы

### Возобновляемые
- [ ] Древесина.
- [ ] Урожай / плодородие.
- [ ] Рыба.
- [ ] Дикие животные.
- [ ] Некоторые растения.

Для них необходимы скорость восстановления и возможность истощения при чрезмерной эксплуатации.

### Ограниченные
- [ ] Железо.
- [ ] Уголь.
- [ ] Медь.
- [ ] Золото.
- [ ] Другие руды.
- [ ] Отдельные каменные/глиняные месторождения, если это оправдано балансом.

Запас месторождения должен реально уменьшаться по мере добычи.

## 3.5 Истощение и восстановление
- [ ] Вырубленный лес снижает лесной потенциал чанка.
- [ ] Лес постепенно восстанавливается естественно или через посадку.
- [ ] Чрезмерное земледелие способно снижать плодородие.
- [ ] Севооборот/удобрение/отдых земли восстанавливают плодородие.
- [ ] Чрезмерный вылов снижает рыбный ресурс.
- [ ] Рудные месторождения не восстанавливаются.
- [ ] Мир должен помнить изменения профиля территории после перезагрузки.

## 3.6 Разведка территории
Игрок не знает точные характеристики мира сразу.

### Уровень 0 — неизвестная территория
- [ ] Только базовая информация после визуального обнаружения.

### Уровень 1 — разведано
- [ ] Биом.
- [ ] Приблизительное плодородие.
- [ ] Лесной потенциал.
- [ ] Доступ к воде.

### Уровень 2 — изучено
- [ ] Камень и поверхностные ресурсы.
- [ ] Предварительные признаки руд.
- [ ] Особенности территории.

### Уровень 3 — геологическая разведка
- [ ] Тип месторождения.
- [ ] Качество / богатство.
- [ ] Оценочный объём запасов диапазоном.

Пример:

```text
Чанк [18, -7]
Биом: Равнина
Плодородие: Высокое
Лес: Низкий
Камень: Средний
Железо: Не исследовано
Вода: Высокая доступность
Пригодность: Высокая
Особенность: Пойменные почвы (+20% урожайности)
```

После геологической разведки:

```text
Железо: Богатое месторождение
Оценочный запас: 9 000–13 000 ед.
```

## 3.7 Territory Overlay UI
- [ ] Клавиша/кнопка открытия стратегического слоя территории.
- [ ] Видимые границы чанков.
- [ ] Наведение показывает карточку чанка.
- [ ] Переключаемые heatmap-режимы:
  - [ ] Плодородие.
  - [ ] Лес.
  - [ ] Камень.
  - [ ] Руды.
  - [ ] Вода.
  - [ ] Пригодность к строительству.
  - [ ] Контроль территории.
- [ ] Цветовая шкала должна быть читаемой, но не перекрывать Minecraft-мир.
- [ ] Неисследованные ресурсы отображаются как неизвестные, а не раскрываются через UI.

## 3.8 Стратегическое значение
Система чанков должна напрямую создавать игровой цикл:

**разведка → оценка территории → специализация → добыча → истощение → торговля / расширение → конфликт**

- [ ] Лучшие сельскохозяйственные районы становятся ценными для продовольствия.
- [ ] Лесные районы — для древесины.
- [ ] Горные районы — для добычи.
- [ ] Реки и переправы — для инфраструктуры и обороны.
- [ ] Бедная ресурсами территория может быть стратегически важной из-за позиции.
- [ ] Игроку должно быть выгодно владеть разными типами территории, а не только одним «лучшим» биомом.

# Первый вертикальный срез

Минимальная версия, которая уже должна ощущаться как Stone & Banner:

1. Minecraft-мир визуально полностью сохранён.
2. Перспективная камера и управление персонажем сверху/сзади.
3. Небольшая группа поселенцев.
4. HUD: население, продовольствие, казна, благополучие + отдельные материалы.
5. Профиль территории для каждого чанка.
6. Territory overlay с плодородием, лесом, камнем и неизвестной геологией.
7. Один разведчик/механика исследования чанка.
8. Одна ферма, урожайность которой зависит от чанка.
9. Один лесорубный участок, который действительно истощает лесной ресурс.
10. Одно железное месторождение, которое нужно сначала обнаружить, затем разведать.
11. Blueprint постройки и рабочий, физически строящий её из Minecraft-блоков.
12. Базовый склад и суточное производство/потребление.

После этого уже можно расширять систему в сторону армии, торговли, городов и политики.
